# CAU: Semester Survivor — terminal edition

The C++ game core playing on its own, in a terminal. No browser, no npm, no libraries: one
C++ file with all the game data built in (balance, courses, professors, rooms, and the text in
English, Russian and Uzbek).

## Build and play

You need a C++17 compiler. On a Mac that is Xcode's command-line tools (`xcode-select --install`).

```bash
clang++ -std=c++17 -O2 cau_semester_survivor.cpp -o cau
./cau
```

- Linux: `g++ -std=c++17 -O2 cau_semester_survivor.cpp -o cau && ./cau`
- Windows (Developer Command Prompt): `cl /std:c++17 /O2 /EHsc /utf-8 cau_semester_survivor.cpp` then `cau.exe`

Make the terminal window at least **78 × 26** characters.

## Controls

| Key | Action |
|---|---|
| W A S D or arrow keys | Move (tap or hold) |
| — | Semicolons fire automatically at the nearest paper |
| Space | Dash ("all-nighter") |
| Q | Throw coffee (Nescafe is saved for bosses) |
| H | Call the professor (once per stage) |
| R | Reload early |
| X | Leave the room |

On screen: `@` you, `;` your semicolons, `q h L ~ P G` pop quizzes, homework, lab reports, loose
pages, projects and group projects, `M` the mid-term (`V` when it folds into a plane, `X` where
it will land), `F` the final, `A B C D` answer bubbles, `*` red-pen marks, `-` staples, `▒` desks,
`c N % + B` MacCoffee, Nescafe, canteen food, deadline extension and the Feynman Lectures,
`&` the attendance sheet, and the red wall is 23:59 coming for you.

Options: `--lang ru` or `--lang uz`, `--reset` (forget progress), `--bot` (watch a scripted student
play a whole semester). Progress is saved to `cau_save.txt` in the current folder.

## What it is made of

`cau_semester_survivor.cpp` is generated by `make_single_file.py`, which joins the game core in
`cpp/src/` (the same code the browser version runs as WebAssembly), the data from `src/data/`
(via `embed_data.py`) and the terminal front end in `main.cpp`. After changing any of those, run:

```bash
python3 cpp/standalone/make_single_file.py
```

The browser game is still the full version: campus map, pixel art and sound. The terminal edition
plays the same semester (quests, every stage and boss, grades, shop, transcript) from a menu.
